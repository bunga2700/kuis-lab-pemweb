# To-Do List 📝

To-Do List dibuat untuk mengelola tugas sehari-hari. Pengguna bisa melihat, menambahkan, memperbarui, dan menghapus tugas.

Setiap tugas memiliki informasi berupa judul, deskripsi, status pengerjaan, tingkat prioritas, dan deadline. Data awal yang ditampilkan menggunakan data dummy.

## Fitur Aplikasi

Aplikasi ini memiliki beberapa fitur utama, yaitu:

- **Menampilkan Tugas:** Menampilkan daftar tugas dalam bentuk tabel yang berisi judul, status, prioritas, deadline, dan aksi.
- **Menambahkan Tugas:** Menambahkan tugas baru melalui formulir yang berisi judul, deskripsi, status, prioritas, dan deadline.
- **Melihat Detail Tugas:** Melihat informasi lengkap dari tugas yang dipilih.
- **Memperbarui Tugas:** Mengubah informasi tugas melalui tombol Update pada halaman detail tugas.
- **Menghapus Tugas:** Menghapus tugas dengan konfirmasi terlebih dahulu sebelum penghapusan dilakukan.

Status pengerjaan tugas terdiri dari To Do, In Progress, dan Done. Sementara itu, tingkat prioritas terdiri dari Low, Medium, dan High.

Seluruh perubahan data dikelola menggunakan React State agar penambahan, pembaruan, dan penghapusan tugas bisa langsung tampil tanpa perlu memuat ulang halaman.
